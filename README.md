Source for my portfolio site: **https://rohitabrahamgeorge.github.io/**

Projects are grouped by category, each running live, each linked to its repository.

| Category | Page |
| --- | --- |
| Website Projects | [/websites/](https://rohitabrahamgeorge.github.io/websites/) |
| Claude Skills | [/#skills](https://rohitabrahamgeorge.github.io/#skills) |

Each website project lives in its own repository with GitHub Pages turned on, so it is served at `rohitabrahamgeorge.github.io/<repo-name>/` and previewed live here.

## Add a new website project

1. Create the project repository and turn on **Settings → Pages** (branch `main`, folder `/ (root)`).
2. Copy the `<article class="project">` block in `websites/index.html` (and on `index.html` if it should be featured) and point `data-src`, the links and the poster image at the new repo.
